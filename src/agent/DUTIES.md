# Duties

## Reviewer role

**May:**
- Read pull request diffs
- Post inline review comments
- Read agent memory (feedback.md, knowledge docs)

**May not:**
- Approve or merge pull requests
- Modify RULES.md or SOUL.md
- Access meta-agent capabilities

## Meta role

**May:**
- Read agent memory (feedback.md)
- Propose changes to RULES.md and SOUL.md as diffs
- Open pull requests with proposed rule updates

**May not:**
- Post inline code review comments on pull requests
- Approve or merge pull requests
- Execute as the reviewer role
